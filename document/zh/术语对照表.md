## F. 节点名（224 个，随总则 0-2 决策）

**建议（0-2 选 B 时）分三档：**
- **F1 常用图形类（译）**：Custom Node 自定义节点 / Merge 合并 / Artboard 画板 / Blend 混合 / Rasterize 栅格化 / Load Image 加载图像 / Mask 遮罩 / Clipping Mask 剪贴蒙版 / Path 路径 / Text 文本 / Image 图像 / Color Value 颜色值 / Gradient Value 渐变值 / Noise Pattern 噪声图案 / Qr Code 二维码
- **F2 调色/图像处理类（译）**：Brightness Contrast 亮度对比度 / Hue Saturation 色相饱和度 / Levels 色阶 / Exposure 曝光 / Gamma Correction 伽马校正 / Invert 反相 / Black And White 黑白 / Channel Mixer 通道混合器 / Selective Color 可选颜色 / Posterize 色调分离 / Vibrance 自然饱和度 / Luminance 亮度 / Threshold 阈值 / Opacity 不透明度节点
- **F3 数学/逻辑/字符串类（保留英文）**：Cosine、Lerp、Modulo、Regex Replace、String Concatenate、As F64、Greater Than 等约 150 个 —— 程序员术语，翻译后反而难与文档/社区对照
